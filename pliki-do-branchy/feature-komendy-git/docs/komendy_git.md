# Lista komend Git użytych w projekcie

git init – tworzy nowe repozytorium Git  
git add . – dodaje pliki do staging area  
git commit -m "message" – zapisuje zmiany  
git status – pokazuje stan repozytorium  
git log – pokazuje historię commitów  
git branch – pokazuje branche  
git switch – przełącza branch  
git merge – łączy branche
